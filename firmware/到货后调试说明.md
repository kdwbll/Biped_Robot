# 开发板到货后：调试顺序

项目主程序已在 ESP32 Dev Module / Arduino 下编译通过，尚未在实物运行。两个测试工程分别打开，各自烧录会替换开发板上已有程序。

1. 核实开发板、舵机、电源和 BNO 模块实物型号、供电极性、电压及引脚；拍照留存。不要按商品图假设最终接线。
2. 先用 USB 单独连接 ESP32，确认电脑识别串口。
3. BNO：确认模块支持的供电、I2C 模式及电平后，接 SDA=21、SCL=22、GND 和正确电源，烧录 hardware_tests/i2c_scan。串口 115200，每 5 秒扫描。扫描成功不等于姿态功能正常。主程序使用 0x4B、INT=19、RST=18；模式和地址根据实物确认。
4. 单舵机：确认电源允许范围及极性，电源断开时连接舵机外部电源和 GPIO13 信号，电源负极与 ESP32 GND 共地；先将舵机从机构上拆开并固定本体。烧录 hardware_tests/servo，串口 115200，发送选择换行，先输入 1500，再测试 1450 或 1550；支持 1400、1600、off。off 停止控制脉冲，并不切断电源或保证舵机释放。出现异常立即关闭舵机电源。限制范围仅是初步测试，不能保证任何实际型号或机构安全。
5. 单舵机及 IMU 确认后，再做悬空联调和支撑测试；主程序尚无电脑控制与断线保护，不能直接拿来安全落地行走。

注意：舵机由独立电源供电，不由开发板引脚供电；USB 供电时不要同时接另一电源到 ESP32 5V。商品图 270 度选项与 180 度标签矛盾；2S 满充 8.4V 是否支持也需卖家确认。原代码 servo2/servo4 左右注释互相矛盾；GPIO12 为启动绑带引脚，需实测。舵机偏移不是通用校准值。
