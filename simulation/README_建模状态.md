# 双足机器人 MuJoCo 建模状态

## 文件与复现
- .venv: 独立 Python 环境，MuJoCo 3.17.0。
- biped_static.xml：全身静态展示，网格不可用于准确碰撞。
- single_leg_mesh_experiment.xml / second_leg_mesh_experiment.xml：分别为一条腿的简化平面闭环实验，附带原 CAD 网格。不是整机模型。
- axis_candidates.json：来自 SolidWorks 同心配合的轴及零件关联，坐标属于各自子装配体。
- meshes_original_coords：保留原装配坐标的网格；meshes_second_leg_local 将第二条腿网格转换到其子装配体坐标。
- verify_mesh_legs.py：运行两腿约束和数值稳定性测试。

## 已验证
两条腿均为 7 刚体、8 条连接约束，约束雅可比秩 16，18 个平面广义自由度留下 2 个独立运动；零重力、任意微小力矩 2 秒仿真，最大约束残差约 1.3e-7 m。此测试不是实物动态或准确度验证。

## 当前阻碍和限制
尚未确认实际舵机、舵盘与各个刚体的对应。第一条腿模型中两个上方关节的瞬时角度并不独立，用它们作为两独立舵机输入将造成重复控制；候选组合可数学独立，但不能因此断言就是实际驱动。静态姿态、简化平面假设和约束冗余也可能影响结论。需核对视频或实际装配后重建真实驱动。
两腿尚未连接机身或旋转舵机；质量、摩擦、舵机响应是未知；碰撞禁用；mesh 为视觉，惯量是假设；不可用于训练或实机控制。原作者的 CAD 不必然反映实际安装细节。

## 第五舵机与髋部候选模型
用户选择的第五舵机轴圆边，主装配坐标轴心约 (-0.026663,-0.006475,0.266320) m、竖直轴；所属机身 2026-04-23-16-40-03-958-1。圆边位置并不单独给出齿轮齿数或啮合方向。
biped_hip_assumption_experiment.xml 假设两大齿轮等速反向，两个齿轮轴心从零件包围盒估计；5 个输入包含腿部四驱和一个候选髋部输入。暂未表示小齿轮相对于大齿轮的传动比，也未验证支撑碰撞、转向限位或实机动作。零重力小力矩 3 秒数值检查：闭环连接最大误差 7.7e-8 m，两轴耦合误差约 3.9e-6 rad。此测试不等于实机正确或可训练。

## 大齿轮中心与候选齿比
用户说明大齿轮通过四个阵列孔固定。SolidWorks 中读取到第一大齿轮四个直径4 mm孔中心为 (57,32)、(42,17)、(27,32)、(42,47) mm，平均中心 (42,32) mm；齿轮曲面中心也为 (42,32) mm。另一大齿轮的局部齿轮中心也是 (42,32) mm，经装配变换映射到机身；实验中两轴的水平坐标与该结果一致。两个齿轮大致相同。
读取圆柱齿顶和齿根面，两个大齿轮各有对应面50组，小齿轮对应面23组，提示可能的齿数比 50:23；需人工或进一步几何核实，不能当成确认齿数。biped_gear_ratio_candidate.xml 只用于实验，采用 23/50 比例和啮合反向的假设，加入独立小齿轮轴，但小齿轮视觉仍包含在固定机身网格。无重力仿真 3 秒，最大连杆位置误差约 1.2e-7 m、齿轮约束最大角误差约 4e-4 rad。关节参数、齿轮约束、接触和功率均未实测，不能用于走路训练或实机控制。

## 自由机身与脚底接触的初版实验
biped_free_contact_experiment.xml 增加自由基座、重力、简化盒形脚底碰撞和机身碰撞盒。两脚、机身碰撞均仅为近似，舵机、连杆惯量及质量尚未实测。机身假定 0.7 kg、各杆件假定 0.05 kg，总质量约1.401 kg，齿比仍是几何面计数推测。真实脚底形状、质量分布、齿间间隙、背隙、伺服响应均没有标定。

无控制下，模型会倒下；test_assumed_hold.py 以临时 PD 和 ±0.5 Nm 假设保持四关节及转向，10 s 内数值有限，机身仍有明显偏航，不能称为稳定站立或真实控制。test_exploratory_gaits.py 用4种幅值做5秒开环试探：0.06、0.1 rad 两组明显倾倒；0.03 rad 有小位移，但不足以判定步行，结果高度依赖足底代理。尚未训练强化学习。训练前需补充实物舵机速度、可用行程与载荷、整机和零件质量/重心、脚底形状摩擦、齿轮实际齿数和驱动方向；并验证模型与作者步态对应及固定基座几何机构。

复现：在本目录运行 `.venv\Scripts\python.exe test_assumed_hold.py` 或 `.venv\Scripts\python.exe test_exploratory_gaits.py`。这些控制只用于模拟，不适用于硬件。

## 销轴显示版
biped_with_visual_pins.xml 在原有物理闭环连接约束上，按每条腿去重后的6条同心配合轴添加了黄色视觉销轴（每腿6根）。圆柱半径 2 mm、半长45 mm 为便于观察的假设，不代表真实轴长度，轴不参与碰撞、无额外质量；它不替代真实轴杆的设计或实物测量。原本 16 个腿部连接约束和齿轮假设保留，模型加载并运行100步数值有限。真实铰链间隙、轴承和动力学未建模。

## 轴线姿态修正
用户指出原显示的轴偏离孔位。原因是此前使用了独立打开的子装配体姿态的配合坐标，但网格来自主装配体中另一姿态；先前图中的半透明红杆也是人工惯量代理，不是真实连杆。已根据每个零件在子装配体与主装配体中的变换，将16条配合轴换算到主装配体姿态，再映射到两腿各自局部坐标，沿轴线投影到建模平面；每个配合两侧轴线的距离经计算小于 1e-6 m。已重新生成两腿约束、模型和黄色轴显示，隐藏红色代理几何但保留其假定惯量。biped_with_visual_pins.xml 为修正后版本。黄色轴的真实长度和各轴摩擦仍未验证，平面建模近似仍存在。之前错误轴线下的运动和步态测试结果不能用于判断修正后模型。

## 碰撞问题与部分修正
用户发现脚穿入地面和连杆互相穿透。原模型可见 mesh 均关闭自动碰撞，仅有两个脚底盒及机身盒，因此之前不应认为它们是完整实体碰撞。整机也没有站立控制。
self_collision_split_candidate.xml 为部分修正：地面与腿部可见网格使用显式接触对；对每腿部分零件（part1、2、4、5、6）的独立网格分块并取凸包，生成共33个凸碰撞片，对非直接铰接零件及跨腿零件启用碰撞。初始接触为0；无控制自由下落2秒测试中观测最大地面穿透约0.45 mm、已启用的自碰撞穿透约0.22 mm。MuJoCo软接触允许少量穿透，不代表真实材料指标。每腿 part0、part3 等及直接铰接对尚未建立完整自碰撞；机身和腿之间碰撞尚未完整建模，局部凸包近似可能误报/漏报。关节限位、动力学、舵机控制仍不可靠，不可训练或上实机。

## 按用户指定材料构建的质量与碰撞候选版
biped_chassis_collision_candidate.xml：基于 SolidWorks 68 个可见实体的几何体积、几何质心估计；以实心材料密度1240 kg/m³计算推定打印件，尺寸与位置匹配的5个舵机候选实体各0.055 kg。每个 MuJoCo 刚体包含多个 CAD 实体，其质心为这些实体几何质心按质量加权；转动惯量按实体包围盒估计并合并，不是精确惯量。完整明细见 cad_mass_inventory.json。模型另有12根直径4 mm、暂定长度90 mm的显示轴按304不锈钢8000 kg/m³计入约0.10857 kg；轴长、数量与实物未核实。忽略电源和线缆等未建模零件；打印件按实心计算，不等同含填充率的真实打印重量；舵机候选实体可能包含附属几何。
计算 CAD 实体约2.83322 kg、暂定钢轴约0.10857 kg、数值轴占位约0.001 kg，总计约2.94279 kg，仅为当前几何假设下的计算值。
碰撞在前一版基础上，膝部各新增12块凸近似，并对两腿部分零件、非直接连接部分及机身12块可分离凸近似建立接触，初始无接触；2秒无控制下落测试计算有限、地面最大穿透约0.474 mm、已启用自碰撞最大约0.341 mm、连杆连接最大偏差约0.098 mm。未覆盖所有同轴相接或直接铰接的实体、上部复杂结构及销轴接触；凸近似仍可能漏碰或误碰。模型无站立控制、惯量与机械限位近似，不能用于实机和正式训练。

## 重心对称初始姿态
biped_centered_initial_pose.xml 中包含 keyframe centered_start；注意直接用普通 Viewer 加载 XML 不会自动设为该关键帧。运行 view_centered_pose.py 会先加载关键帧再打开 Viewer。求解参考两只脚简化脚底碰撞盒的几何中心和模型总质心：水平中点与重心投影误差小于0.001 mm，脚底网格最低点高度差小于0.001 mm，初始零穿透，闭环连接误差小于0.001 mm。由于当前质量分布与两侧脚/连杆结构不完全对称，允许机身侧倾约0.80度才满足这些静态几何目标；没有施加站立控制或验证动态稳定性，脚底可能只有局部接触。为计算精度而非模型真实性：几何、质量、质心、钢轴长度及碰撞均仍为估计，实际误差未知。旧文件 balanced_initial_pose.npz 为不倾斜近似解，左右中点距重心约2.69 mm，不是精确对称解。
