## 2. SolidWorks 中不通电核对

1. 使用另存或只读方式打开装配，记录机器人的前方、背面和左右定义；相机视角变化不应改变左右定义。
2. 每次只核对一个舵机，隐藏遮挡零件或设为透明。标注舵机外壳、输出轴、舵盘、与舵盘螺接的零件、该零件带动的连杆。
3. 测量该舵机输出轴轴线的位置和方向。轴线同心只能说明同轴，不能单独证明哪个零件和舵盘刚性固定。
4. 在已有配合允许、不会改坏原装配的情况下检查动作；不能拖动时记录为“未验证”，不要通过临时删除配合去断定运动关系。每个舵机记录由其驱动的一条连杆和受动的其他连杆。
5. 第五舵机记录小齿轮、大齿轮、两个腿部支架的连接与转动方向；50:23 及反向关系目前仍是候选。大齿轮可通过四个阵列孔固定，中心没有孔也可求旋转中心。
6. 分别记录理想站姿下各舵机轴、连杆姿态与脚底方向。机械是否能够继续移动，用不通电的装配几何和允许的运动范围评估；不要强扳舵机。

## 3. 单个舵机空载测试记录（实物与电源规格确认后）

仅在舵机与连杆/舵盘脱开、接线和电源额定值核实后，对单个舵机测试。图中型号选项写270°而外壳图标180°，实际版本应先由标签或卖家确认。信号脉宽是命令，不是 ESP32 读到的实际角度反馈。

- 测试前做好断电检查；舵机电源和电源限流依据实际铭牌/可靠规格书设置，并留意电源是否进入限流。不用 ESP32 GPIO 或 3.3V 引脚给舵机供电。
- 如果 ESP32 由 USB 供电、舵机由独立稳压电源供电，需要连接公共 GND；不要将舵机供电正极接到 ESP32 GPIO/3.3V。具体端子仍需按实物标签确认。
- 舵机未受机械约束时才发送中立命令；首次上电可能跳转。1500 μs 可作为待核实的控制参考，不保证是实际机械中点或安全安装零位。
- 在可见位置作标记，使用很小的脉宽增减、逐步观察方向和电流，出现卡住、异常鸣叫、发热或突发电流时立即断电。不要靠撞击机械止挡去寻找极限；留出余量并等待真实机构限位确认。

## 4. 站姿与仿真修正

- 对每个轴分别记录：舵机参考脉宽、安装姿态、正方向、保守范围、几何减速比，以及这些数据的来源。方向和零位按测得结果映射，候选值必须标记假设。
- 以真实装配的初始机身高度、足底姿态和质量为目标，先测试无虚拟辅助的中立姿态；同时记录高度变化、关节跟踪误差、倾角、力矩和每个物理子步的数值峰值。只看“没有倒”不够。
- 舵机的控制增益、质量、负载与摩擦未测量时做参数敏感性实验；在0.5 ms与0.25 ms等步长复核。稳定数值不等于证明实物表现。
- 分别在 SolidWorks 和 MuJoCo 中核对7处CAD干涉以及之前被剔除的55组候选碰撞对，区分实际不应接触、允许接触、齿轮啮合与碰撞代理误差；不能一概启用或禁用。修订应另存独立候选模型并记录原因。
- 用同一动作序列比较CPU/GPU的位姿、足底接触、连杆误差、限位越界、数值溢出，并检查不同步长和长时稳定性。只有这些测试达到项目约定标准后，才进行正式世界模型数据收集。
